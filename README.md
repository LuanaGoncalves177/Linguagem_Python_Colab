# Linguagem_Python_Colab
# 🐍 Linguagem Python no Google Colab

Este repositório reúne um conjunto de notebooks e projetos práticos desenvolvidos em **Python** no ambiente **Google Colab**. O conteúdo abrange desde os fundamentos da linguagem até projetos práticos de Análise de Dados, ETL, Estatística e Dashboards.

---

## 📁 Conteúdo do Repositório

* **`Python_Guia_da_linguagem_.ipynb`**: Conceitos fundamentais de Python (variáveis, estruturas condicionais/repetição, listas, dicionários e introdução ao NumPy).
* **`Python_Análise_de_dados.ipynb`**: Manipulação e exploração de dados utilizando bibliotecas essenciais como `pandas`.
* **`Análise_de_Scores_de_Clientes.ipynb`**: Projeto prático focado em análise comportamental e métricas de clientes.
* **`python_etl.ipynb`**: Pipeline de Extração, Transformação e Carga (ETL) de dados.
* **`Python_Desafio_de_Regressão_linear.ipynb`**: Aplicação de modelagem preditiva e regressão estatística em Python.
* **`Python_Visualização_&_Dashboars.ipynb`**: Criação de gráficos visuais, relatórios e dashboards iterativos.
* **`Python_Desafios.ipynb`**: Resolução de desafios práticos para consolidação do aprendizado.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebooks
* **Principais Bibliotecas:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

---

## 🚀 Como Executar

1. Escolha qualquer um dos notebooks `.ipynb` na lista acima e clique nele.
2. Na parte superior da visualização do arquivo no GitHub, clique no botão **"Open in Colab"**.
3. O projeto será aberto diretamente no Google Colab pronto para ser executado ou editado.
